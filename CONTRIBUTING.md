# Contributing

## Local development

Open `index.html` in a browser. The site is static, so there is no build step, package install, backend, or network access required for local development.

## Pull request previews

Pull request previews are published under `/previews/pr-N/` and linked from a PR comment.

The preview workflow also captures desktop and iPhone screenshots, uploads them as workflow artifacts, and embeds the hosted screenshots in the PR comment.

## Production publishing

Production is served by GitHub Pages from the `gh-pages` branch root. Merges to `main` publish the production site automatically.
